# apps/web

The Next.js frontend. It has the run form (demo-site picker plus a paste-any-URL box) and the live run view (BrowserPanel, TraceTimeline, LadderStepper, DiagnosisCard, VerdictCard). It also has the results page and a `/dev` page that renders the sample stream with no API key.
Phase 1 sets it up (shell, generated types, `/dev`). Phases 2–4 build the run view and Phase 5 builds the results page.
