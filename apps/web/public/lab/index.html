Test pages built to trip web agents

Each page hides its data in one specific way, so a live run on it shows one failure class of Agent Failure Autopsy. All data on them is fictional.

  • Northlight Box OfficeNeeds interaction: the 2019 chart loads only after clicking its tab.
  • Fernwood KitchenPopup: a cookie consent wall hides the products, then a newsletter popup covers them.
  • Larkspur Spring collectionMisread: only 6 of 12 products show until "View all" is clicked.
  • Northlight accountLogin wall: redirects to a sign-in page that never lets anyone in.
  • Larkspur beta sign-upCaptcha: the form can't be submitted without solving a CAPTCHA that always fails.
  • Harbor Lamp product pageBot block: answers every request with HTTP 403.
